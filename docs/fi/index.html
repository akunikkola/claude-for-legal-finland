Kaikki on rakennettu sen varaan, että laki tarkistetaan lähteestä eikä muistista, viittaukset kantavat kolmiportaisen varmuusmerkinnän ja lopussa on ihmisen tarkistusportti. 01

Suoja syntyy mekanismeista

Lähteestä, ei muistista

Säädökset ja oikeuskäytäntö haetaan Finlexistä sekä oikeuslähde-MCP:stä (oik.ai tai laki.ai). Jokainen kokoelman säädösnumero on varmistettu lähteestä ennen julkaisua.

Kolmiportainen varmuus

Varmistettu · Tarkistettava · Älä käytä. Jokainen viittaus ja laskelma kantaa varmuusmerkintänsä sen numeron vieressä, jota se tukee — ei yleisenä varaumana kappaleen lopussa.

Negatiivirajaus

Jokainen skill kertoo, mitä se EI tee: ei kartelliapua, ei todisteiden hävitystä, ei keksittyjä pykäliä, ei rikoksen peittelyä.

Ihmisen tarkistusportti

Jokainen tuotos on luonnos. Pätevä ihminen tarkistaa, päättää ja kantaa vastuun — työkalu nopeuttaa tarkistusta, ei korvaa sitä.

Asennus ja käyttöönotto

Kokoelma nojaa Agent Skills -spesifikaatioon ja AGENTS.md-käytäntöön. Claude Code ja Codex ovat kaksi tuettua harnessia, eivät lähtökohta — mikä tahansa Agent Skills -muotoa lukeva harness voi käyttää näitä kokonaisuuksia suoraan, ilman erillistä plugin-järjestelmää.

claude code
/plugin marketplace add ragmha/agent-skills-for-finnish-law
/plugin install legal-core@agent-skills-for-finnish-law

Lisää oman alasi oikeudenalat samalla tavalla, esimerkiksi employment-law@agent-skills-for-finnish-law.

codex
node scripts/generate-adapters.mjs
codex plugin marketplace add .
codex plugin add legal-core@agent-skills-for-finnish-law

Jos oikeudenalan mcp.json määrittelee oik-ai-palvelimen, tarkista tila komennolla codex mcp list --json ja kirjaudu komennolla codex mcp login oik-ai.

mikä tahansa muu harness
cp -r <oikeudenala>/skills/* <harnessin-skills-hakemisto>/

SKILL.md on puhdasta Agent Skills -muotoa ilman toimittajakohtaisia laajennuksia. Jos harness tukee MCP:tä, osoita se tiedostoon <oikeudenala>/mcp.json.

Tuota sisältöä Ilmoita virheestä

Jokainen tuotos on tarkistettava luonnos. Kyse ei ole oikeudellisesta neuvonnasta, eikä tämä kokoelma tai sen sisältämät ominaisuudet korvaa juristia. Vastuun lopputuloksesta kantaa aina käyttäjä, ja käyttöä suositellaan ainoastaan kouluttautuneille oikeudellisen alan ammattilaisille. Skillit on rakennettu tämän mukaisesti: laki ja oikeuskäytäntö tarkistetaan lähteestä eikä muistista, jokaiseen viittaukseen tulee lähdemerkintä, jurisdiktio-oletukset pidetään näkyvissä, ja ennen kuin mitään lähetetään tai allekirjoitetaan, asian varmistaa ihminen. Suojan tuottavat mekanismit — lähteen varmistus, kolmiportainen varmuusmerkintä, premissien tarkistus, negatiivirajaus ja ihmisen tarkistusportti. Mekanismit on koottu tiedostoihin references/citation-style.md ja references/liability-and-security.md.

Tämä on yhteisön avoin hanke, ei viranomais-, lakiasiain- tai asianajopalvelu, eikä se edusta minkään organisaation virallista oikeudellista kantaa. Kuka tahansa voi kontribuoida hankkeeseen omat skill-tiedostonsa, joista on ollut todistettavaa hyötyä omassa työssä.
