Twenty-four practice-area domains of open-source skills, subagents and guardrails for legal work in Finland — legal language, statute citation and real legal sources (Finlex, oik.ai, KKO/KHO, HE). Every feature is built on checking the source rather than recalling it, three-tier certainty labelling and a human review gate. 01

Protection comes from mechanisms

From the source, not from memory

Statutes and case law are fetched from Finlex and a legal-source MCP (oik.ai or laki.ai). Every statute number in the collection is verified against the source before release.

Three-tier certainty

Verified · To be checked · Do not use. Every citation and every calculation carries its certainty label next to the number it supports, not in a blanket caveat at the end.

Negative scoping

Every skill states what it does NOT do: no cartel help, no destroying evidence, no invented statutes, no covering up crime.

Human review gate

Every output is a draft. A qualified human checks, decides and bears responsibility — the tool speeds up review, it does not replace it.

Subagents — delegable work steps

Source checkerlegal-core/agents/source-checker.md

Assumes every citation is wrong until the source proves otherwise. Returns a verification table with fix suggestions — run it on every document that goes out.

Deadline scannerlegal-core/agents/deadline-scanner.md

Scans every deadline in the material, calculates them cautiously from both possible start dates, and surfaces the most urgent first. Calendar responsibility stays with the human.

Opposing counseldispute-resolution/agents/opposing-counsel.md

A simulator of the other side’s counsel: attacks your brief in earnest and returns a weakness table, your strengths and the top three fixes before you file.

Material mappercompany-law/agents/material-mapper.md

Inventories the data room by DD area, produces a gap list ready to send as an information request, and red flags for prioritisation. An inventory — not a legal assessment.

Deviation checkercontracts/agents/deviation-checker.md

Compares a draft against the house risk policy clause by clause and points out what to escalate. Stops if there is no yardstick — it does not invent “market practice”.

Confidentiality assessoradministrative-law/agents/confidentiality-assessor.md

Prepares a public-access assessment point by point with statutory grounds and produces a redaction proposal. Partial disclosure as the rule; the official decides.

Installation & onboarding

The collection targets the Agent Skills specification and the AGENTS.md convention. Claude Code and Codex are two supported harnesses, not a premise — any harness that reads the Agent Skills format can use these bundles directly, with no plugin system required.

claude code
/plugin marketplace add ragmha/agent-skills-for-finnish-law
/plugin install legal-core@agent-skills-for-finnish-law

Add your practice-area domains the same way, for example employment-law@agent-skills-for-finnish-law.

codex
node scripts/generate-adapters.mjs
codex plugin marketplace add .
codex plugin add legal-core@agent-skills-for-finnish-law

If a domain’s mcp.json declares the oik-ai server, check it with codex mcp list --json and sign in with codex mcp login oik-ai.

any other harness
cp -r <domain>/skills/* <harness-skills-dir>/

SKILL.md is plain Agent Skills format with no vendor extensions. If the harness supports MCP, point it at <domain>/mcp.json.

For organisations

Before production use: a data policy, a processing agreement (GDPR Art. 28), anonymisation as a workflow and a named review chain — see references/firm-adoption.md. House conventions are recorded with the practice-profile skill in legal-core, and the shared source, liability and security lines live in references/ at the repository root.

Every output is a draft for review. This is not legal advice, and neither this collection nor its features replace a lawyer. The user always bears responsibility for the outcome, and use is recommended only for trained legal professionals. The skills are built accordingly: law and case law are checked against the source rather than from memory, every citation carries a source mark, jurisdiction assumptions are kept visible, and before anything is sent or signed a human verifies it. Protection comes from mechanisms — source verification, three-tier certainty labelling, premise checking, negative scoping and the human review gate. The mechanisms are collected in references/citation-style.md and references/liability-and-security.md.

This is an open community project — not an authority, legal or attorney service — and it does not represent any organisation’s official legal position. Anyone can contribute their own skill files that have proven useful in their own work.
